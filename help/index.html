常见问题

歇刻支持哪些设备？

当前公开预览版支持 macOS 14 及以上的 Apple Silicon Mac。下载前请核对产品页的系统与芯片要求。

安装包和版本信息来自哪里？

安装包由 haers/xieke-releases 公开发行仓提供。官网展示核对后的版本快照，下载入口指向相应版本文件；历史版本可从 GitHub Releases 查看。

为什么首次打开可能需要确认？

当前歇刻属于 ad-hoc 签名预览版，尚未经过 Apple 公证。请先核对下载来源，再根据 macOS 的提示处理。遇到无法启动的问题，可以附上系统版本和提示内容反馈。

书库和资料馆的链接有问题怎么办？

可以在相应网站的反馈入口提交，也可以在下方选择对应项目，附上具体页面和问题描述。

官网会收集我的使用数据吗？

本站未接入访客统计、广告或账号系统。主题偏好仅保存在当前浏览器；反馈在访客确认后交由 GitHub 处理。GitHub Pages 作为托管服务会记录访问日志。
